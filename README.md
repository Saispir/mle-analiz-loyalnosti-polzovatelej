Анализ лояльности пользователей Яндекс Афиши.

В этом проекте я поработал с реальными данными сервиса Яндекс Афиша. Здесь пользователи могут узнавать о мероприятиях в разных городах и покупать на них билеты. Яндекс Афиша сотрудничает с организаторами мероприятий и билетными операторами, которые публикуют информацию и выставляют билеты на продажу.
Мне нужно помочь команде маркетинга лучше понять поведение пользователей. Для этого нужно провести исследовательский анализ данных, чтобы выяснить, какие пользователи с большей вероятностью возвращаются на платформу и делают заказы повторно. Это позволит решить несколько задач:
-быстро выявлять перспективных клиентов и предлагать им персонализированные условия;
-точно настраивать рекламу на аудитории с высокой вероятностью возврата;
-оптимизировать маркетинговые бюджеты;
-повысить общий уровень удержания клиентов.
Проект состоял из 4 частей:
-Знакомство с данными. 
-Подготовка к выгрузке данных. 
-Исследовательский анализ данных. 
-Инженерная часть проекта. 

Для запуска проекта:  
python3 main.py
